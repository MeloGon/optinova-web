# Drive: índice de clases e informes (2026-11-01)

Entrega completa de Optinova: **17 lecciones, 3 informes y este índice**, 21 PDF. Los nombres y el orden de las carpetas permiten continuar leyendo desde otra computadora.

## 1. Qué subir ahora

Si ya conservas las clases anteriores en Drive, añade estos cuatro PDF: `09-vender.pdf`, `10-egresos.pdf`, `11-historial-ventas.pdf` y `2026-11-01-informe-de-avance.pdf`. Añade también `08-revisiones-medidas.pdf` si aún no lo habías subido. El índice sirve como lista de control.

Para tener la biblioteca completa, usa la carpeta `docs/informes/drive-2026-11-01/` o descomprime `docs/informes/optinova-drive-2026-11-01.zip`. En Google Drive, usa **Nuevo → Subir carpeta** y selecciona la carpeta descomprimida. Subir solo el ZIP sirve como respaldo, pero no deja las clases individuales listas para leer.

Los PDF van a Drive para leer e imprimir; los Markdown son fuentes editables y permanecen en GitHub. Los archivos `.layout.json` y el manifiesto de verificación quedan fuera del paquete.

## 5. Regenerar los documentos

Cada fuente Markdown se convierte con `npm run pdf -- <archivo.md>`. Las lecciones están en `docs/lessons/`, los fundamentos en su subcarpeta `fundamentos/` y los informes recientes en `docs/avance/`. Este índice se regenera con:

```bash
npm run pdf -- docs/entregas/2026-11-01-drive.md
```

El script histórico `scripts/docs/build-delivery.mjs` conserva la fecha 2026-10-26 y su informe. Esta entrega fechada se preparó por separado, sin modificar ese script ni borrar informes antiguos.
